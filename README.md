# work-items

Optional GitHub work-item templates and deterministic tracking tools.

Published as plugin `work-items` from this repository's `work-items-agents` marketplace.

## Skills

- Utilities: `work-items:manage`.

## Authoring and verification

```powershell
pwsh .agents/sync-generated.ps1
pwsh .agents/sync-generated.ps1 -Check
```

The layout, the vendored generator and CI come from [kit](https://github.com/tj-agents/kit).
